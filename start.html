학생용 · 1차시 전

시작 전 준비

첫 수업에서는 GitHub에 앱 파일을 저장하고 Streamlit Community Cloud에서 앱을 배포합니다. 수업 전에 학교 컴퓨터에서 두 서비스에 로그인하고, 선생님이 안내한 AI 도구에서 새 대화를 열 수 있는지 확인하세요.

연령 조건은 각 서비스의 이용약관을 따릅니다. 학교 방침은 선생님의 안내를 따르세요. 공용 PC에서는 처음부터 브라우저의 시크릿 창이나 사생활 보호 창을 사용하세요.

① 학교망에서 세 사이트를 여세요

  • GitHub에서 첫 화면이나 로그인 화면이 열리는지 확인하세요.
  • Streamlit Community Cloud에서 로그인 안내나 내 앱 목록이 열리는지 확인하세요.
  • 선생님이 안내한 주소로 학교에서 허용한 AI 도구를 여세요. 첫 화면이나 학교 계정 로그인 화면이 보이는지 확인하세요.
막히면 · 학교에서 사이트가 열리지 않습니다

주소를 다시 확인하세요. 학교의 접속 제한 안내가 표시되면 어느 사이트에서 어떤 문구가 나왔는지 선생님께 알리세요. AI 도구 주소를 모르면 수업 공지의 링크를 확인하세요.

② 인증 메일을 받을 이메일을 준비하세요

학교에서 사용을 허용한 이메일의 받은편지함을 여세요. GitHub에 가입하면 이 주소로 인증 메일이 옵니다. 가입 화면과 받은편지함을 각각 열어 두면 메일에 있는 코드나 링크를 바로 확인할 수 있습니다.

막히면 · 학교 메일로 인증 메일을 받을 수 없습니다

가입을 시작한 뒤 메일이 오지 않으면 입력한 주소와 스팸함을 확인하세요. 주소가 맞으면 가입 화면에서 Resend 또는 ‘인증 메일 다시 보내기’를 선택하고 가장 최근 메일을 여세요. 학교 메일이 외부 인증 메일을 차단하면 선생님께 알리고 학교에서 허용한 다른 주소나 인증 방법을 안내받으세요.

③ GitHub에 가입하고 이메일을 인증하세요

  1. GitHub에서 Sign up(가입)을 선택하세요. 이미 계정이 있으면 Sign in(로그인)을 선택하고 본인 계정인지 확인하세요.
  2. 가입 화면에 준비한 이메일과 비밀번호를 입력하세요. Username은 저장소 주소에 공개됩니다. 실명과 학번이 들어가지 않는 별명을 정하세요.
  3. 받은편지함에서 GitHub의 인증 메일을 열고, 화면의 안내에 따라 코드를 입력하거나 인증 링크를 여세요. 로그인한 뒤 프로필 메뉴에서 정한 사용자 이름을 확인하세요.
  4. 2단계 인증을 요구하면 안내에 따라 설정하세요. 복구 코드는 인증 기기를 사용할 수 없을 때 필요합니다. 본인만 다시 꺼낼 수 있는 곳에 보관하세요. 공용 PC에 내려받은 사본이 있으면 개인 보관본을 확인한 뒤 지우세요.
막히면 · 가입 버튼이 보이지 않거나 사용자 이름을 쓸 수 없습니다

좁은 화면에서는 메뉴를 열어 ‘가입’ 또는 Create account를 찾으세요. 이미 사용 중인 이름이라는 안내가 나오면 다른 별명을 정하세요. 메일 인증에서 멈추면 ②의 안내를 확인하세요. 본인이 사용할 수 있는 2단계 인증 방법이 보이지 않으면 해당 단계의 이름을 선생님께 알리세요.

④ Streamlit Community Cloud에 GitHub를 연결하세요

Streamlit Community Cloud에서 Sign in을 선택하세요. 로그인 방법에서 Continue with GitHub 또는 GitHub로 계속하는 항목을 고르세요. GitHub의 연결 승인 화면에서 내 사용자 이름과 연결을 요청한 서비스가 Streamlit인지 확인하고 Authorize(연결 허용)를 선택하세요. 돌아온 화면에서 내 작업 공간이나 앱 목록을 확인하세요. 처음에는 목록이 비어 있을 수 있습니다.

막히면 · 로그인했는데 GitHub 연결을 다시 요청합니다

먼저 GitHub의 프로필에서 로그인한 계정을 확인하세요. 다른 사람의 계정이면 로그아웃하고 내 계정으로 다시 시작하세요. 내 계정이 맞으면 Streamlit 화면에서 Connect GitHub 또는 ‘GitHub 계정 연결’에 해당하는 항목을 찾으세요. 버튼 이름이 달라졌다면 현재 화면의 제목과 선택 항목을 선생님께 보여 주세요.

⑤ 선생님이 안내한 AI 도구에서 새 대화를 여세요

①에서 확인한 수업용 AI 도구에 학교가 허용한 방식으로 로그인하세요. 새 대화 또는 New chat을 선택하고 메시지를 입력할 수 있는지 확인하세요. 아래 문장으로 응답을 확인할 수 있습니다.

접속 확인용 프롬프트
급식 메뉴를 보고 답할 수 있는 질문을 하나만 써 줘.
막히면 · 새 대화나 메시지 입력 칸이 보이지 않습니다

메뉴를 펼쳐 대화를 시작하는 항목을 찾으세요. 학교 계정을 선택하는 화면으로 돌아가면 수업에 쓰는 계정인지 확인하세요. 사용 권한을 요청하는 문구가 표시되면 그 문구를 선생님께 알리세요.

⑥ 공용 PC에서 로그아웃하고 시크릿 창을 닫으세요

AI 도구, Streamlit Community Cloud, GitHub, 이메일의 계정 메뉴에서 각각 로그아웃 또는 Sign out을 선택하세요. 비밀번호 저장을 묻는 창에서는 ‘저장 안 함’을 선택하세요. 사용한 시크릿 창을 모두 닫으세요.

막히면 · 다음 사람이 열었을 때 내 계정이 표시됩니다

일반 창에도 로그인했는지 확인하고 해당 서비스의 계정 메뉴에서 로그아웃하세요. 계정 선택 화면에 내 계정이 남으면 해당 계정의 ‘이 기기에서 삭제’ 항목을 찾으세요. 학교가 관리하는 브라우저에서 이 항목을 찾을 수 없으면 선생님께 알리세요.
