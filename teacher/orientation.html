두근두근 급식실 개강 전 안내

첫 시간에 학생은 급식 앱을 배포하고 짝의 휴대폰에서 버튼을 눌러 봅니다. 수업 전에 학생이 사용할 기기로 교재를 열고, 예시 앱의 버튼을 누르는 데까지 확인해 주세요. 나이스 인증키와 한 달치 급식 자료는 2차시부터 사용합니다.

1. 학교망에서 열어 볼 주소

학생이 사용하는 무선망과 계정으로 확인합니다. 접속이 막힌 경우 아래에서 해당 주소와 용도를 골라 학교망 담당자에게 허용을 요청합니다. 배포 관리 화면과 학생이 여는 앱의 주소가 다르므로 두 곳을 각각 확인합니다.

허용 요청 주소용도학교 기기에서 확인할 일
greatsong.github.io/dugeun-lunch-claude/GitHub Pages 웹 교재. 학생에게는 이 주소만 안내합니다. 교사용 목차는 끝에 teacher/를 붙인 주소입니다.학생용 목차에서 1차시를 엽니다.
github.com학생 계정과 앱 저장소로그인하고 수업용 저장소의 파일을 엽니다.
share.streamlit.ioStreamlit Community Cloud 배포 관리GitHub 계정을 연결하고 배포할 저장소를 선택할 수 있는지 확인합니다.
*.streamlit.app배포한 앱 실행교사가 미리 배포한 실제 앱 주소를 열고 버튼을 누릅니다. 별표는 앱마다 달라지는 주소 부분을 뜻합니다.
open.neis.go.kr나이스 인증키 신청과 급식 조회포털의 인증키 신청 화면을 엽니다. 교사 앱에서도 학교 검색과 중식 조회를 시험합니다.
raw.githubusercontent.com수업용 급식 CSV 원본아래의 준비 파일 주소를 열어 첫 줄의 열 이름과 첫 날짜를 확인합니다.
학교 승인 AI 도구의 접속·로그인 주소앱 생성과 수정 요청학교가 지정한 로그인 방식으로 새 대화를 열고 답변을 받을 수 있는지 확인합니다.

2. 사용할 AI 도구와 학생 계정

교사가 학교 승인 도구를 정하고 아래 내용을 학급 공지에 옮겨 주세요. 입력한 내용은 이 페이지에 저장되지 않습니다. 작성한 안내를 보관하려면 인쇄하세요.

가입 시기와 학생·보호자 동의 절차는 학교 방침에 따릅니다. GitHub의 가입 최소 연령은 만 13세이며, 사용하는 서비스별 연령 조건과 학교 계정의 외부 서비스 이용 권한도 확인합니다. 가입 승인을 기다리는 학생은 짝이 직접 조작하는 화면이나 교사 시연으로 참여할 수 있습니다.

  1. 학생용 안내를 엽니다. 학교망을 확인한 뒤 시작 전 준비를 안내합니다. 학생이 직접 인증 메일을 받을 수 있는 이메일을 준비합니다.
  2. GitHub 계정을 준비합니다. 이름과 학번이 드러나지 않는 공개용 별명을 정하고 이메일 인증을 마칩니다. 2단계 인증을 설정하고 복구 코드는 본인이 관리하는 곳에 보관합니다.
  3. 배포 계정을 연결합니다. Streamlit Community Cloud에서 자신이 사용할 GitHub 계정으로 로그인하고 저장소 연결을 허용합니다. 첫 저장소를 만들고 두 파일을 올리는 활동은 1차시에 함께 합니다.
  4. 지정한 AI 도구에 접속합니다. 새 대화를 열 수 있는지 확인합니다. 공용 기기에서는 사용을 마친 뒤 AI 도구, Streamlit, GitHub와 이메일에서 로그아웃합니다.

3. 2차시 급식 자료 준비

기본 방법 · 나이스 인증키로 조회합니다

  1. 나이스 교육정보 개방 포털에 가입하고 로그인합니다. 포털의 인증키 신청에서 발급 절차를 진행합니다.
  2. Streamlit Community Cloud에서 해당 앱의 설정을 열고 Secrets를 선택합니다. 아래 예시의 따옴표 안을 발급받은 값으로 바꾸어 저장합니다. 학생에게 화면을 공유하기 전에 설정 창을 닫습니다.
  3. 앱이 Secrets에서 NEIS_API_KEY를 읽도록 합니다. 학교명과 지역을 확인한 후 한국 시간 기준 지난달 1일부터 말일까지의 중식을 조회합니다. 서로 다른 급식일 수, 받은 행 수, 나이스 응답의 전체 건수를 화면에서 대조합니다.
앱 설정의 Secrets에 작성할 형식
NEIS_API_KEY = "발급받은 인증키"
교사 키는 교사가 관리하는 앱에서 사용합니다

학생이 저장소나 앱 코드를 수정할 수 있으면 그 코드로 Secrets의 값을 읽을 수 있습니다. 교사 키를 학생 소유 앱에 대신 입력하거나 학급 공지로 배포하지 마세요. 학교 방침에 따라 개별 키를 사용하는 경우에는 각 발급자가 자기 앱의 Secrets에 직접 입력합니다. 코드, AI 대화, 공개 게시물에 실제 키가 들어갔다면 해당 키를 폐기하고 새 키를 설정합니다.

키가 없거나 조회가 막힐 때 · 준비한 CSV를 불러옵니다

학생에게 키를 배포하기 어렵거나 나이스 접속·인증 오류로 조회할 수 없으면 아래 파일로 수업을 진행합니다. 파일은 2026년 10월 당곡고등학교 중식 15일분입니다. 화면에 ‘준비 파일 · 당곡고등학교 · 2026년 10월’이라고 표시해 학생이 실제 사용한 학교와 기간을 알 수 있게 합니다.

선생님이 준비한 급식 파일 주소
https://raw.githubusercontent.com/greatsong/dugeun-lunch-claude/main/data/danggok_lunch_202610.csv

2026년 10월 당곡고 중식 CSV 열기

파일의 열수업 전 확인 예
MLSV_YMD급식일입니다. 첫 행의 20260901은 2026년 10월 1일입니다.
MMEAL_SC_NM식사 구분입니다. 이 파일에는 ‘중식’이 들어 있습니다.
DDISH_NM하루 메뉴입니다. 첫날의 ‘친환경칼슘기장밥’과 ‘육개장 (1.5.6.13.15.16)’ 사이에 있는 <br/>가 메뉴 구분 기호입니다.

인증키 없이 나이스를 시험해 받은 최대 5건은 일부 자료일 수 있습니다. 이 자료로 시연할 때는 ‘조회된 급식일의 반찬 순위’라고 표시합니다. 한 달 전체의 순위를 구하는 실습은 인증키로 전체 건수를 확인하거나 위 CSV를 불러와 진행합니다. 인증키로 정상 조회했으나 급식이 없는 기간이라면 ‘조회한 기간에 중식 자료가 없습니다’라고 안내하고, 준비 파일을 열 때는 자료가 바뀌었음을 표시합니다.

4. 교재 구성과 차시별 대응

학생용 페이지와 교사 진행안은 차시 번호가 일대일로 대응합니다. 교실에는 학생용을 보여 주고 교사는 같은 번호의 진행안에서 시간표, 발문, 예상 오류와 관찰 기준을 확인합니다. 1~4차시는 같은 앱을 이어서 고치며, 5~8차시는 팀이 고른 문제로 앱을 만듭니다. 팀 앱은 급식 API 없이도 만들 수 있습니다.

차시학생 페이지교사 진행안
1 · 공통우리 학교 급식으로 어떤 앱을 만들 수 있을까?바이브코딩으로 만드는 첫 급식 앱과 배포
2 · 공통지난달 우리 학교 점심을 빠짐없이 불러왔을까?나이스 급식 API를 활용한 학교 검색과 월별 중식 조회
3 · 공통지난달 우리 학교 급식에 가장 자주 나온 반찬은 무엇일까?반찬별 제공 일수 집계와 대시보드 시각화
4 · 공통친구는 설명 없이도 반찬 1위를 바로 찾을 수 있을까?디자인 씽킹의 사용자 관찰을 통한 대시보드 개선
5 · 팀우리 학교 급식에서 어떤 문제를 골라 누구를 도울까?디자인 씽킹의 공감과 문제 정의, 페르소나와 여정 지도
6 · 팀우리 앱의 첫 화면에는 어떤 정보와 버튼이 필요할까?린 스타트업의 최소 기능 제품(MVP) 구현과 사용성 관찰
7 · 팀고친 화면에서 새 친구는 혼자 해낼 수 있을까?린 스타트업의 반복 개선과 사용성 재점검
8 · 팀우리가 완성한 앱으로 누가 무엇을 할 수 있을까?팀 앱 완성과 짝 시연을 통한 핵심 기능 공유

교원 연수 안내에는 연수 8차시가 한 페이지에 정리되어 있으며, 해당 교사 진행안으로 이동할 수 있습니다. 학생용 부록에는 나이스 문서 발췌, 오류가 났을 때 확인할 사항, 공개 전 점검표가 있습니다.

5. 공개 범위

이 교재에는 차시 잠금이 없습니다. 모든 페이지가 처음부터 열려 있어 학생이 앞 차시를 다시 보거나 다음 차시를 미리 읽을 수 있습니다. 교재는 공개 저장소에 있으므로 누구나 HTML과 데이터 파일을 읽을 수 있습니다. 실제 인증키, 학생 정보, 비공개 평가 자료는 교재 저장소에 올리지 않습니다.

첫 수업 전 마지막 확인

  • 학생 기기에서 교재, 지정 AI 도구, GitHub와 배포 관리 화면을 열었습니다.
  • 학교 방침에 따라 계정 준비 시기와 동의 절차를 안내했습니다.
  • 교사의 예시 앱을 다른 기기에서 열고 ‘급식실 열기’를 눌러 보았습니다.
  • 공개 전 점검에서 개인정보 입력란, 얼굴 사진, 코드 속 인증키를 어디서 확인할지 정했습니다.
  • 2차시에 사용할 인증키 조회와 준비 파일 경로를 확인했습니다.
